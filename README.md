# 🛒 پروژه MyShop

این پروژه یک فروشگاه ساده است که با زبان C# نوشتم و هدفم از ساختنش تمرین مفاهیم برنامه‌نویسی و آشنایی بیشتر با ساختار پروژه‌های بک‌اند بوده.

### امکانات پروژه
- مدیریت محصولات
- ثبت و مدیریت مشتریان
- ثبت سفارش
- محاسبه مبلغ سفارش
- بررسی موجودی محصولات
- کاهش موجودی بعد از ثبت سفارش

### تکنولوژی‌های استفاده‌شده
- C#
- .NET
- Entity Framework Core
- SQL Server

### ساختار پروژه
پروژه به چهار بخش تقسیم شده:

- **Entities:** کلاس‌ها و مدل‌های پروژه
- **DAL:** ارتباط با دیتابیس
- **BLL:** منطق برنامه
- **UI:** بخش اصلی اجرای برنامه

### هدف من
هدف اصلی من از این پروژه یادگیری بهتر C#، درک ارتباط بین بخش‌های مختلف برنامه و تمرین معماری چندلایه بوده.
